# Ignore-key add overlay

## Goal

「添加按键」用一层盖住整扇设置窗的轻遮罩来录一枚忽略键，让人看清按下的是什么，再主动确认后才写入。

## Requirements

1. 键盘图留在设置页。遮罩只服务「添加按键」，盖住整扇设置窗，包括标签栏。
2. 打开后钩子一直武装，直到确认、取消、点遮罩、设置窗失焦或窗口卸载。每一记按键按下换成当前候选。按下和松开都不进 HUD。鼠标照常，关闭后 HUD 恢复正常投送。
3. 还没有候选时，只显示「请按下要忽略的键…」，不显示键名。「确认」禁用。
4. 已有候选时，提示改为「再按一次可更换」，下面显示短标签和原始 id（与忽略列表同一套）。
5. 候选已在忽略列表里：短标签和 id 用红色，其下方用次要灰色小字写明「已在忽略列表」，「确认」禁用，不重复写入。每次按下已在列表中的同一枚键，只让短标签和 id 播放一次短的 CSS 位移动画，说明文字保持不动，且不再渐入。换一枚键，或再按同一枚尚未忽略的键，短标签和 id 做一次短渐入。有效键不震动。系统开启减少动态效果时两种动画都不播放。
6. 候选尚未忽略：「确认」可点。点它才写入这一枚，然后解除武装并关闭。再加下一枚要重新点「添加按键」。
7. 「取消」和「确认」一直都在，且只响应鼠标。任意按键（含 Esc、Enter、Space）只更新候选。
8. 点遮罩或点「取消」丢弃候选并关闭。设置窗失焦同样丢弃并关闭。

## Acceptance Criteria

- [x] 添加按键不再在列表旁切换成「取消 + 请按键」，而是打开整窗遮罩。
- [x] 连续按键只更换候选，不写入、不关闭、不进 HUD。
- [x] 无效候选为红色，键名下有灰色「已在忽略列表」，确认不可点；再按同一枚已忽略的键，只有键名和 id 短震，说明文字不动、不渐入。换键或再按同一枚尚未忽略的键时，键名和 id 短渐入。有效候选确认可点，点击后列表多这一枚并关闭遮罩。
- [x] 点遮罩、点取消、设置窗失焦都不写入。
- [x] Esc 不会关闭遮罩；它成为候选键。

## Out of Scope

- 把忽略键盘图搬进遮罩。
- 一次确认多枚键。
- Esc 作为退出键。
