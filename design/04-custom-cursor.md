# 自定义鼠标指针（grilling 共识）

> 来源：2026-09-19 grilling。**仅产品共识记录，未开工。**  
> 总览入口：`design/index.md`。实现前须另建 Trellis 任务并写 `prd` / `design` / `implement`。

## 一句话

录屏用**真换肤**：功能开启时在主屏**全局隐藏系统光标**并自绘内置贴图；不改 HUD chip / 捕获主链路语义。

## 已锁定

| 项 | 决定 |
|----|------|
| 形态 | 真换肤（藏系统光标 + 自绘），不是跟班贴图，也不是「用窗盖住箭头」（OS 光标层盖不住） |
| 开关 | 独立；默认关；不绑 `captureMouse` / HUD 预设 |
| 生效范围 | 全局：其它 App 在前台也必须换肤 |
| 平台 / 屏 | 一期仅 macOS / Windows **主屏**；Linux、外接屏贴图不做 |
| 离主屏 | 立刻恢复系统光标并隐藏贴图；回到主屏再藏系统光标并显示贴图 |
| 光标种类 | 永远同一张所选预设（不映射 I 型 / 手型 / 缩放等） |
| 点击反馈 | 无按压态；不与涟漪强制联动（涟漪仍独立） |
| 素材 | 仅内置预设；不自选本地文件 |
| 预设数量 | 2：默认「高对比圆点」；另备「经典箭头皮肤」 |
| 尺寸 | 固定（预设自带）；无缩放滑杆 |
| Hotspot | 每预设自带（圆点=中心；箭头=尖）；绘制 tip 对齐物理指针 |
| 设置入口 | `CapturePanel`，放在点击涟漪旁（开关 + 预设选择） |
| 托盘 | 无换肤快捷开关（与涟漪一致） |
| 藏光标失败 | 硬失败：开不了或运行中自动关 + 短提示；**不**降级双影 / 跟班模式 |
| 生命周期 | 关功能 / 退 App 必 `unhide`；启动若发现异常残留 hide，先复位再应用设置 |

## 明确不做（一期）

- 用户自选图片；尺寸 / 透明度 / hotspot 用户可调
- 光标种类映射；仅替换 arrow、其它种类恢复系统光标
- 跟班偏移贴图（系统光标仍显示）作正式模式或失败降级
- 托盘开关；独立看门狗进程
- 外接屏贴图；Linux；皮肤市场
- 改 `HudChip` / Text·Lite·Full 展示逻辑

## 与现有能力关系

- **涟漪**：同属主屏可选装饰；独立开关；可同开。换肤不要求开涟漪。
- **捕获**：换肤需要指针位置（今日钩子无 move，实现时另开位置通路）；位置事件**不**进 chip 时间线。
- **「鼠标轨迹 / 位置指示器」**（`index.md` 二期池）：跟班式指示器仍不做；本共识是**替换光标**，另立条目，不混为一谈。

## 风险（实现时必处理）

- 全局 hide 计数与退出路径；崩溃后依赖进程结束恢复，但不能当唯一设计
- 全屏游戏 / 远程桌面等抢光标 → 走硬失败策略
- 主屏进出边界的 hide/unhide 闪烁可接受，丢光标不可接受
- move 推送频率：须节流，避免拖垮前端
