## 一、HTML / 结构 & 可用性问题

### 1. Tab 键盘逻辑（`onkeydown={onTabListKeydown}`）

你已经绑定了事件，但建议确认实现：
Tablist 标准要求：

- ← → 在tab之间切换
- `Home` 跳到第一个tab，`End`跳到最后一个
- Enter / Space 激活选中tab> 
> 目前代码骨架是对的，只要`onTabListKeydown`实现这套逻辑，无障碍就完整。

### 2. `disabled` 控件的对比度风险

`disabled` 的 select/input，浏览器默认会把文字变淡。
你现在没有单独写 `:disabled` 样式，**部分浏览器里可读性会下降**。
建议统一加一条：

```
select:disabled,
input:disabled {
  opacity: 0.45;
  cursor: not-allowed;
}
```

### 3. Capture 区域的提示文字（hook状态）

```
{#if hookOk === true}
  Input hook is active.
{:else if hookOk === false}
  Input hook failed — grant Accessibility in System Settings, then restart.
{:else}
  Waiting for hook status…
{/if}
```

> 
> 很好，但建议**增加颜色区分**：成功用绿色，失败用红/橙，不要全是muted灰色。

```
<p class:ok={hookOk === true} class:error={hookOk === false} class="muted">
```

```
.ok { color: #86efac; }
.error { color: #fca5a5; }
```

### 5. 滚动区域溢出行为

`.panel` 设置了 `overflow-y:auto`，但外层多层嵌套 `min-height:0`，这个写法本身没问题。
⚠️ 注意：当设置项很多时，滚动条会紧贴面板边缘，可以给 `.panel` 增加横向内边距，避免内容贴到滚动条。

## 二、CSS 样式层面优化建议


### 2. 圆角统一规范

现在圆角值零散：

- select/input: `border-radius:10px`
- clear按钮：`8px`
- log容器：`10px`

✅ 建议**全局统一圆角变量**，保持整套UI一致性（Tauri应用很看重这点）

```
:root {
  --radius-sm: 8px;
  --radius-md: 10px;
}
```

然后所有控件复用变量。

### 3. Tab 下划线 hover 缺少过渡

当前tab切换下划线是瞬间变化，加个过渡会更顺滑：

```
.tab {
  transition: color 120ms ease, border-color 120ms ease;
}
```

### 4. Field 间距

`.field { gap:8px }`，标题和控件之间8px，在小窗口里略紧凑。
可选调到 `gap:10px`，呼吸感更好。

### 5. Log 面板

`.log` 背景 `rgba(15, 23, 42, 0.72)`

> 
> 日志面板半透很好看，但注意：**日志文本很长时，白色文字在半透背景上，低亮度屏幕可读性下降**。
> 备选方案：不透明背景 `#0b1220`，或者提高不透明度到0.9。

### 6. 颜色拾取器 `input[type="color"]`

现在高度固定40px，在Windows上原生color输入框样式差异很大，部分系统会裁剪。
可以改成 `min-height:40px`，不要固定height。

## 四、微小细节、风格统一建议

1. 单位统一：你现在混合px，没有用rem。
桌面Tauri工具，**直接px完全没问题**，不用强行rem，这个不用改。
2. 阴影：目前全局几乎没有阴影，整体是扁平化。
如果想增加一点层次感，可以给输入控件增加微弱 `box-shadow: inset 0 1px 0 rgba(255,255,255,0.04)`，增强悬浮控件的立体感，不突兀。
3. 按钮hover状态：`.clear` hover只改文字和边框，可以增加背景色轻微提亮：

```
.clear:hover {
  background: #1e293b;
}
```

## 五、风险点提醒

1. **macOS 权限提示文案**

> 
> `grant Accessibility in System Settings, then restart.`
> mac系统里，**授予辅助权限后，必须完全退出程序（不是关闭窗口）**，建议文案微调：
> Input hook failed — enable Accessibility permission for this app in System Settings, then fully restart the app.
