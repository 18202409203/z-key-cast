## design/03 — HUD UX（已交付）

来源需求拆为 Trellis 父任务 `09-17-design-03-hud-ux`（四子任务均已 archive）。此处只保留锁定摘要。

### 执行顺序（完成）

1. `09-17-hud-settings-schematics` — 设置形态图卡  
2. `09-17-has-numpad-toggle` — 有无小键盘（板形）  
3. `09-17-scroll-wheel-hud` — 滚轮方向脉冲  
4. `09-17-text-key-queue` — Text/Lite 操作时间线  

### 小键盘可选

- 捕获区手选「有小键盘」；默认关；只影响 Full/Capture `KeyboardMap` 是否画小键盘列  
- 与忽略 Numpad 分离；错配不自动忽略；不做自动检测  

### 滚轮行为增强

- 有限开放：`{ kind: "scroll"; direction: "up" | "down" }`；仅纵向；强合并  
- 受 `captureMouse` 总闸；用 `ignoredMouseActions`（含 `"scroll"`）关闭滚轮 HUD；无独立 `captureScroll`  
- Full：滚轮刻度方向脉冲（不跟速度）；与按键高亮不互斥  
- Text/Lite：滚轮进操作时间线（与键/鼠同队；同向撞队尾只刷新 dwell）  

### UX：面板预设 / 键鼠布局

- 预设 1×3 形态死图卡 + 可见标签，替换分段条  
- 键鼠布局 1×4 构图死图卡 + 可见标签；**仅 Full 显示**（Text/Lite 固定右入左移时间线）  

### Text / Lite 操作时间线（锁定）

- 同队上限由 `timelineMax`（默认 5，范围 1–10）控制；键 + 鼠键 + 纵向滚轮；右入左移；满则丢最旧；调小 N 立刻丢最旧；每条独立 `dwellMs`  
- Text：`formatHudLabel` — 鼠/滚轮随 UI 语言（en: `LMB`/`Scr↑`；zh: `左键`/`滚↑`）；Lite：KeyCard + 缩小 MouseSchematic 五态定帧  
- status 清整队后独占；Full 仿真路径不变  
- **出字方向**：固定 LTR 右入左移（新在右）；**不**随角落水平镜像；不做 `timelineGrow` 选项  
- **贴右**：角 = 最新（live edge）；**贴左**：角 = 行首/旧端，新键往屏心长
